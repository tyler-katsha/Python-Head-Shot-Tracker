# Python Head Shot Tracker

A real-time head/face tracker using Python and OpenCV, with optional hand gesture detection for interactive applications. 
This project detects faces, tracks key landmarks, and provides visual feedback on head position.  

---

## Features
- Real-time head/face detection using Face Mesh.
- Tracks specific landmarks (e.g., forehead, nose tip).
- Draws target points, crosshairs, and coordinates for visualization.
- Optional hand gesture detection integrated via HandTrackingModule.
- FPS counter for performance monitoring.
